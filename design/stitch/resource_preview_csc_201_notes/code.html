Figure 4.2: Self-Balancing BST Node Structure & Left Rotation
Algorithm: InOrder(Node root) Time: O(n) 
1:  if root == NULL then return
2:  InOrder(root.left)
3:  PRINT(root.key)  // Visits in sorted order
4:  InOrder(root.right)

Tip: In-order traversal of a valid BST always outputs elements in ascending non-decreasing key sequence.
